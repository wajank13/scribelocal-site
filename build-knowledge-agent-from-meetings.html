Example Claude Projects instruction

You are an internal knowledge assistant. Use the uploaded Markdown files as the primary source of truth. When answering, cite the relevant meeting, date, project, or source file when possible. Prioritize decisions, requirements, risks, action items, and implementation details found in the knowledge base. If the information is not available in the uploaded files, say that clearly.

Note: ScribeItLocal creates local Markdown files on your device. You can choose to upload those files to Claude or other AI tools. Claude is a cloud service operated by Anthropic and does not run locally — ScribeItLocal handles the private, local preparation step.

    team-meetings/

    risks/
  04-agent-ready/

    by-client/
    by-topic/
  05-local-search-index/

This keeps original files, generated transcripts, summaries, and agent-ready knowledge separated so the content can be reused across Claude Projects, local search, RAG systems, or future agent tools.
